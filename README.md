# Floppy

### A Beautiful File Manager for Android.

**Floppy** is a modern, beautifully designed file manager built with Flutter, focused on delivering a premium file management experience on Android.

Featuring an exclusive **Broken Icon Pack**, AMOLED-friendly dark mode, fluid animations, and an elegant interface, Floppy makes managing files simple and enjoyable.

More than just a file explorer, Floppy brings your files and media together with built-in video and audio players, an image viewer, and a text editor — all in one place.

---

## ✨ Features

### 🎨 Premium UI/UX
- Beautiful textured and alpha-blended interface.
- Modern glassmorphic visual experience.
- Exclusive Broken Icon Pack.
- Dynamic AMOLED-friendly dark mode.
- Smooth transitions and iOS-style bouncy animations.

### 📁 Smart File Management
- Browse and manage files and folders.
- Copy, cut, paste, rename, and delete operations.
- Advanced file sorting and organization.
- Quick access to important file categories.
- Visual internal storage overview.

### 🖼️ Native Media Gallery
- Fast native media indexing.
- Dedicated Images, Videos, and Audio categories.
- No slow recursive storage scanning.
- Sort media by Newest, Oldest, and Date-wise.

### 🎬 Built-in Media Players

**Video Player**
- Powered by `media_kit`.
- Smooth high-resolution video playback.
- High-performance media rendering.

**Audio Player**
- Elegant and minimal playback interface.
- Album artwork support.
- Precise seeking and playback controls.

**Image Viewer**
- Full-screen image viewing.
- Smooth pinch-to-zoom gestures.
- Detailed image browsing with `photo_view`.

### 📝 Built-in Text Editor
- Open and edit text files directly.
- Supports `.txt`, `.md`, `.json`, and other code files.
- Convenient file viewing and editing.

### 📊 Storage Overview
- Visual representation of internal storage usage.
- Quick understanding of available and occupied space.
---

## 🔐 Permissions

Floppy requires the following Android permissions for its core functionality:

| Permission | Purpose |
|---|---|
| `MANAGE_EXTERNAL_STORAGE` | Access and manage files across device storage. |
| `READ_MEDIA_IMAGES` | Read and index image files. |
| `READ_MEDIA_VIDEO` | Read and index video files. |
| `READ_MEDIA_AUDIO` | Read and index audio files. |

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Flutter & Dart | Application development |

## 🚀 Getting Started

### Prerequisites
- Flutter SDK installed.
- Dart SDK.
- Android device or emulator.
- Android API 21 or above.

### Installation

**1. Clone the repository**

```bash
git clone <YOUR_REPOSITORY_URL>
```

**2. Navigate to the project directory**

```bash
cd Floppy
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```
